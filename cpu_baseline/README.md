# CPU baseline


## How to access

In order to run the `main.cpp` file giving the png image of the set you require, follow these steps:

1. Clone the repository
2. In the terminal, paste this instruction: `cd Mandelbros/cpu_baseline`
3. Paste the following command into the terminal: `source run.sh`
4. Follow the steps in the terminal to generate the desired image

## HDMI

To run the `display_hdmi.py` script, make sure you have pygame installed first.

Then there are two ways to use the script, one locally on your device display, or connecting HDMI to a second display.

To test locally, copy and run this `python3 display_hdmi.py --test`.

To test with external display, make sure you connect a second display and select `Extend` rather than mirror.

Then copy and run this `python3 display_hdmi.py`.

When done, press `Q` or `ESC` to close.
